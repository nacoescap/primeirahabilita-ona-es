Baixe uma cópia completa dos seus dados para o seu computador. Faça isso antes de qualquer mudança importante no sistema. O arquivo fica salvo no seu computador, não depende da internet e pode ser guardado onde você quiser.

Backup completo

Um único arquivo .json com absolutamente tudo: leads, alunos, metas, vendedores, origens, motivos, usuários e empresas. É este arquivo que permite restaurar o sistema depois.

Planilhas (Excel)

Baixa um arquivo .csv para cada tabela, que abre direto no Excel ou no Google Planilhas. Bom para conferir ou analisar os dados, mas não serve para restaurar.

Restaurar backup

Recoloca no banco os dados de um arquivo de backup. Registros com o mesmo código são sobrescritos; os demais são mantidos. Use apenas se algo der errado.
